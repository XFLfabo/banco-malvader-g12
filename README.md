# banco-malvader-g12
Sistema bancário simples para cadastro e manutenção de contas correntes. Cada conta pertence a um único cliente. As operações afetam somente os saldos mantidos em memória durante a execução.
# compilação
-Para compilar use: " g++ main.cpp conta.cpp lista.cpp io.cpp -o banco " (dentro da pasta src)

-Para executar use: " ./banco "
